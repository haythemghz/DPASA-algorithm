\subsection{Function Definitions}

The CEC2017 benchmark suite contains \textbf{30 test functions} categorized into four groups. 
All functions are shifted and rotated versions of basic mathematical test functions.

\begin{itemize}
    \item \textbf{Search Range:} $[-100, 100]^D$ for all functions
    \item \textbf{Standard Dimensions:} $D \in \{10, 30, 50, 100\}$
    \item \textbf{Recommended Runs:} 51 independent runs per function
    \item \textbf{Max Function Evaluations:} $10{,}000 \times D$
\end{itemize}

\noindent\textbf{Key Features:}
\begin{itemize}
    \item Winner of CEC2017 competition
    \item Based on L-SHADE with weighted mutation strategy
    \item Initial population size: $NP_{\text{init}} = 25 \sqrt{D} \log D$
    \item Historical memory size: $H = 5$
    \item Weighted mutation factor $F_w$ varies based on progress
\end{itemize}

\section{Experimental Protocol Recommendations}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

For your paper to meet Q1 journal standards, follow these experimental protocols:

\subsection{Standard CEC2017 Protocol}
\begin{enumerate}
    \item \textbf{Dimensions:} Test on $D = 10, 30, 50, 100$
    \item \textbf{Runs:} 51 independent runs per function (minimum 25 for Q2)
    \item \textbf{Budget:} $\text{MaxFES} = 10{,}000 \times D$
    \item \textbf{Metrics:} Report Mean Error ($f(x) - f^*$) and Std. Dev.
    \item \textbf{Statistics:} Friedman test with Nemenyi post-hoc, Wilcoxon signed-rank
\end{enumerate}

\subsection{Required Comparisons}
For a competitive paper, compare against at least:
\begin{itemize}
    \item jSO (CEC2017 winner)
    \item L-SHADE (CEC2014 winner)
    \item SHADE (baseline adaptive DE)
    \item CMA-ES (evolution strategy baseline)
    \item Standard DE/rand/1/bin
\end{itemize}
